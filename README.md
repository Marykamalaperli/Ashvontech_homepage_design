# Ashvon Technologies — Homepage Design

## Project Overview

This repository contains my individual homepage design implementation for **Ashvon Technologies**, developed as part of our 10-day Frontend Website Development PI.

The project focuses on creating a modern, responsive, user-friendly company website that introduces Ashvon Technologies and provides clear navigation to its two primary service areas:

- **EdTech:** Educational technology solutions for schools and colleges.
- **IT Services:** Technology and software services for businesses and organizations.

This homepage implementation is submitted for team review and design selection.

- Develop a professional and visually appealing homepage.

## Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your system.

### 1. Clone the Repository

```bash
git clone https://github.com/Marykamalaperli/Ashvontech_homepage_design.git
```

### 2. Navigate to the Project

```bash
cd Ashvontech_homepage_design
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the website.

### 5. Build for Production

```bash
npm run build
```

The generated production files will be available in the `dist` directory.
